# WellPack assets

Empty on purpose, as of this sprint's audit.

Unlike SPF (which arrived with ~20 real Figma exports before any chapter
was written), zero real WellPack visual assets exist anywhere in this
project — no wireframes, no landing-page screenshots, no WeData
platform captures, no persona/market-analysis documents, no brand
assets. `content/case-studies/wellpack.ts` (the original 7-section
text-only case study, live at `/work/wellpack`) is the only real
WellPack material on record.

No manifest file (mirroring `content/case-studies/spf-assets.ts`) has
been created here yet, on purpose: that manifest works because someone
already knows and lists the specific filenames expected in each folder.
For WellPack, nobody has specified what real exports exist or are
coming — inventing a list of expected filenames would be a guess, not
a fact. Once real assets start landing, build the manifest against what
actually exists, the same way SPF's was — not ahead of it.
