# foundations

Expected files:

- `colors.webp` — the color foundations, before they became tokens.
- `typography.webp` — the typography scale and usage rules.
- `icons.webp` — the icon set and its usage guidelines.
- `spacing.webp` — the spacing scale.
- `grid.webp` — the layout grid.
- `elevation.webp` — the elevation levels and their use.
- `material-theme.webp` — the Material 3 theme configuration.

These are foundation sheets, not application screens — export the Figma frames that show the system on its own terms (a type scale, a color ramp, a spacing ruler), not a UI that happens to use them.
