# ux

Expected files:

- `user-flow.webp` — a real user flow diagram for one of the core SPF service journeys.
- `information-architecture.webp` — the IA map the interface structure had to earn its way into.
- `wireframes.webp` — low-fidelity wireframes for core screens, tested before any visual decision was made.

These should look like working documents, not deliverables polished for presentation — the point of this section is "every screen exists for a reason," and working documents prove that better than clean renders do.
