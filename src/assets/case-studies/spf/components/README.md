# components

Expected files:

- `overview.webp` — a full sheet showing the component library as one coherent system, not a pile of unrelated pieces.
- `buttons.webp` — button components, all states.
- `inputs.webp` — input field components.
- `pickers.webp` — date and selection picker components.
- `notifications.webp` — notification and alert components.
- `headers.webp` — the header component.
- `sidebars.webp` — the sidebar navigation component.
- `breadcrumbs.webp` — the breadcrumb component.
- `tooltips.webp` — the tooltip component.
- `steppers.webp` — the stepper component.
- `progress.webp` — progress indicator components.
- `radio.webp` — radio and checkbox components.
- `language-selector.webp` — the language selector component.
- `footer.webp` — the footer component.
- `navigation.webp` — the primary navigation component.

This is meant to become the strongest section on the page — export each component with enough of its real states visible (default, hover, focus, disabled, error where relevant) that it reads as engineered, not decorated.
