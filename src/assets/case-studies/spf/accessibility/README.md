# accessibility

Expected files:

- `contrast.webp` — contrast checks run across the token system (a contrast-checker plugin export, or an annotated palette, works well).
- `keyboard-navigation.webp` — keyboard navigation and focus states actually in use.
- `component-states.webp` — component states: hover, focus, disabled, error.

The goal of this section is to show accessibility as a decision, not a checklist — evidence of the _decisions_ (why a state looks the way it does) is more valuable here than a WCAG badge or a generic statement.
